# ⚡ AI Council

Desktop aplikacija koja prikazuje više AI servisa istovremeno u panelima.

## Šta radi

Umesto da skačeš između tabova, vidiš ChatGPT, Claude, Gemini i ostale
u jednom prozoru, rame uz rame.

## Servisi

- ChatGPT
- Claude
- Gemini
- Grok
- Perplexity
- Microsoft Copilot

## Pokretanje

Instaliraj Node.js, zatim:

    npm install
    npm start
